# WebCity — SimCity Web Revival

A SNES SimCity revival built with TypeScript and Phaser 3. City builder with simulation mechanics including traffic, pollution, land value, disasters, and RCI demand.

## Quick Start

```bash
npm install
npm run dev       # http://localhost:5173
npm run build     # Production build
```

## Features

- Procedural city simulation (power grids, crime, pollution, land value)
- RCI (Residential/Commercial/Industrial) demand system
- Auto-tiling roads, power lines, rails with bitmask-based connections
- 3x3 zone system for buildings
- Disasters, tax rates, budget management
- Web Audio API procedural sound effects

Built with Phaser 3, TypeScript, Vite.
